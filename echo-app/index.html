Réglages

Verrouillage par code
Demande un code à 4 chiffres à l'ouverture de l'app. Le code reste uniquement sur cet appareil (aucun compte, aucun serveur) : s'il est oublié, il faut effacer les données pour redéverrouiller l'app.
Rappel quotidien
Affiche un rappel dans l'app (et une notification si autorisée) si tu n'as pas encore journalisé aujourd'hui après l'heure choisie. Ne fonctionne que quand tu ouvres l'app : les navigateurs ne permettent pas de notification fiable app fermée sans service d'envoi payant, donc ce rappel n'est pas garanti si tu n'ouvres jamais l'app dans la journée.
Piste audio (pauses, pics de volume, ton en Hz)
Temporairement désactivée : capturer l'audio en plus de la transcription fait planter la reconnaissance vocale en cours d'enregistrement sur certains téléphones. Le temps de trouver une solution fiable, cette option reste coupée pour ne pas risquer la transcription, qui est la fonction principale d'Écho.

Toutes tes données restent sur cet appareil (aucun serveur, aucun compte). La reconnaissance vocale utilise le moteur de ton navigateur ; selon le navigateur, l'audio peut être traité par le service de reconnaissance vocale du fournisseur (ex. Chrome/Google) le temps de la transcription — rien n'est stocké ni envoyé par Écho lui-même.

Si tu actives la piste audio ci-dessus, elle est aussi conservée sur cet appareil (stockage local du navigateur) pour afficher les pauses et pics de volume — jamais envoyée nulle part. Elle n'est pas incluse dans l'export JSON (fichier trop volumineux) et est effacée avec le bouton "Tout effacer" ci-dessus.

"Ton compagnon" (sur l'écran de résumé) est une fonctionnalité optionnelle qui envoie la transcription du jour et tes scores à un service d'IA (Claude, via une fonction serveur Netlify) pour générer une réponse personnalisée. Elle ne s'active que si une clé API a été configurée côté serveur ; sans elle, l'app continue de fonctionner normalement avec les suggestions locales uniquement. Écho reste un outil de bien-être, pas un substitut à un accompagnement professionnel.
